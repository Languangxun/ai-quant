# cquant · ai-quant 加密市场实验版（纯算法，无 LLM）

这是 [ai-quant](../ai-quant) 的加密市场实验分支：**只做加密 USDT 永续**，**不调用任何
LLM**，全部决策来自本地模型与确定性规则。数据、因子和模型配方复用桌面上的两个项目：

| 来源 | 复用什么 |
|---|---|
| `../sm701` | `crypto_daily` 行情、40 维 tech 因子（`lgbm_train_backtest._compute_feats`）、横截面 beta 中性残差标签、LGBM 选币配方 |
| `../sm702` | 120 维顶部/止损因子（`features.compute_features`）、顶部标签（10 日内先跌 8% 而非先涨 3%）、止损模型配方 |

第一版交付的是**两个模型的融合回测**：sm701 路线负责「买什么」，sm702 路线负责
「什么时候不该持有」，组合层带杠杆、资金费、维持保证金与强平。

## 1. 结论速览

样本外 walk-forward：**2023-01-01 ~ 2026-11-03**（1403 天，10 日调仓，141 次调仓），
初始资金 100,000 USDT，单边手续费 0.05% + 滑点 0.05%，资金费 0.01%/日（净敞口口径）。

| 策略 | 年化 | 年化波动 | Sharpe | 最大回撤 | Calmar | 平均 gross |
|---|---:|---:|---:|---:|---:|---:|
| **fused（双模型融合，纯多头）** | **+48.24%** | 69.64% | **0.92** | **-60.22%** | 0.80 | 1.27x |
| alpha_only_long（只用 sm701） | +46.56% | 77.58% | 0.88 | -73.05% | 0.64 | 1.41x |
| risk_overlay_long（只用 sm702 做门槛/降杠杆） | +40.78% | 69.54% | 0.84 | -59.59% | 0.68 | 1.24x |
| fused_xs（同样的融合分，截面多空） | -4.08% | 40.19% | 0.10 | -60.54% | -0.07 | 1.76x |
| BTC 买入持有 | +49.29% | 46.11% | 1.10 | -52.97% | 0.93 | 1.00x |
| 等权币池 | +11.49% | 69.04% | 0.51 | -83.38% | 0.14 | 1.00x |

逐年（融合策略）：2023 **+199.2%**，2024 **+102.4%**，2025 **-29.2%**，2026（至 11-03）
**+5.8%**。

读法：

- **融合确实降低了尾部风险**：相比纯 sm701 排序，最大回撤从 -73.1% 收到 -60.2%，
  Sharpe 从 0.88 提到 0.92，代价是年化少约 1.7pp。sm702 的价值主要在防守，不在选币。
- **杠杆不是越高越好**：把波动目标关掉、固定杠杆回测，1x 年化 +33.7% / 回撤 -48.8’;
  1.5x 年化 +41.5% / 回撤 -65.1’;**2x 和 3x 都在 2025-10-10 全市场闪崩中触发强平**（当天等权币池单日约 -24%’。默认配置用 35% 目标波动把实际 gross 压在 1.3x 左右。

- **自适应波动目标**：最近 60 日年化波动 < 25% → 目标下调至 25%；> 45% → 目标下调至 30%。默认 35% 在大多数日子保持不变，低波动期自动缩放可防止被动加杠杆。
最近 60 日内若年化波动持续在 25% 以下，实际 gross 会相应压低（见 daily_primary.csv 中 `vol_60h` 与 `target_vol_adj` 字段），这有助于在平静市场降低尾部风险。
- **不要做空山寨**：同样融合分的截面多空版本年化 -4.1%。模型的标签是「相对 BTC 的
  超额收益」，用山寨空头代替 BTC 对冲既没有中性化 beta，又承担逼空风险。
- 这个窗口 BTC 本身年化约 +49%、Sharpe 1.10。融合策略的风险调整后表现仍略逊于
  BTC 买入持有，但显著优于等权币池；它的意义是**用选币 + 风控做出与 BTC 不同源、
  可加杠杆的收益曲线**，而不是稳定跑赢 BTC。

> 以上结果包含研究阶段的参数对比（同一段样本外区间内比较了分散度、风险惩罚、
> 调仓频率、杠杆与对冲方式），存在选择偏差，不应视为可直接上线的业绩承诺。

## 2. 双模型融合逻辑

1. **进攻端（sm701 路线）**
   - 因子：sm701 的 40 维 tech 因子（动量、均线、RSI/KDJ/MACD、布林、ATR、量比、
     截面分位等）。
   - 标签：未来 h=10 日 `R = close[t+h]/open[t+1]-1` 减去 `beta_i · R_btc`
     （90 日滚动 beta），按当日截面中位数二分类；样本权重 = min(截面数, 50)/50 ×
     时间衰减（半衰期 2 年）。
   - 输出：`P(未来 10 日跑赢 BTC)`。
2. **防守端（sm702 路线）**
   - 因子：sm702 的 120 维价量/形态/自身历史分位因子。
   - 标签：从 t+1 开盘算起，未来 10 日内**先跌 8%**、且之前没有先涨 3% 的顶部事件。
   - 输出：`P(顶部)`。
3. **融合**
   - 当日截面把两个概率转成 [-1,1] 百分位分数：`fused = z(alpha) − λ·z(risk)`，默认 λ=0.5。
   - 多头硬门槛：`risk < min(0.45, 当日 85% 分位)`，防止概率分布漂移导致门槛失效。
   - 组合层 regime：当日截面 risk 中位数若处于过去 40 个调仓日的高分位（≥80%/95%），
     把 gross 降到 0.7x/0.4x。
   - 信号做 3 日逐币平滑；已有持仓在排名前 `n+buffer` 内不换（降低换手）。
4. **组合与杠杆**
   - 默认 `hedge_mode: none`：只做多，按当日选币等权分配；可切换 `btc`（多头 alpha +
     按账本 beta 做空 BTC）或 `cross_section`（多 top / 空 bottom，仅作对照）。
   - `leverage` 是目标 gross 上限，`vol_target=35%` 向下缩放；收盘后若
     `gross/equity > max_leverage`，下个开盘自动减仓。
   - t 收盘出信号、t+1 开盘成交；逐日计资金费；按当日 low/high 做维持保证金检查，
     触发即以最差价格强平并进入冷却期。

## 3. 快速开始

```bash
cd /home/lan/桌面/test

# 0) 未来函数审计（特征不变性 / 标签尾部 / 折区间隔离）
python3 -m cquant.cli audit

# 1) 双模型融合回测（逐折重训 + 消融 + 杠杆敏感度）
python3 -m cquant.cli backtest

# 复用已有预测、只重跑组合与报告（快）
python3 -m cquant.cli backtest --reuse outputs

# 2) 最新目标仓位（含杠杆与名义敞口）
python3 -m cquant.cli predict --capital 100000

# 3) 单元测试
python3 -m pytest -q
```

常用参数：`--source walkforward|pretrained`、`--years 2023,2024`、`--start/--end`、
`--leverage 1.5`、`--out outputs_xxx`。配置在 `config/crypto.yaml`。

### 调用 sm701 / sm702 的两种方式

- **重训（默认）**：`cquant/adapters.py` 用 `importlib` 直接加载
  `sm701/lgbm_train_backtest.py` 的 `_compute_feats` 和 `sm702/features.py` 的
  `compute_features` / `compute_labels`，保证因子口径与两个原项目逐位一致；然后按
  各自配方在加密数据上做逐折 walk-forward。
- **冻结模型（`--source pretrained`）**：直接加载
  `sm701/markets_output/crypto_ab_E13_h10.txt` 与
  `sm702/outputs_crypto/models/lgbm_{year}.txt`。sm701 的 alpha 模型训练截止
  2023-12-31，因此该模式只回测 2024-01 之后。

## 4. 回测与成交口径

- **调仓**：每 10 个自然日（加密 24/7，无交易日历），t 日收盘算分，t+1 开盘成交。
- **成本**：手续费 0.05% + 滑点 0.05%（单边）；资金费 0.01%/日，默认按净敞口计
  （`funding_mode: net`），可改 `gross` 做保守口径。
- **杠杆**：权重是权益占比，`gross = Σ|w|`；单币上限 25%；`max_leverage=3`。
- **强平**：`equity_worst <= maintenance_rate × gross` 时以当日最差价格平仓，
  扣 0.5% 强平费，冷却 5 日后才允许重新建仓。
- **基准**：BTC 买入持有、等权币池（日频再平衡）。

## 8. 口径与限制

1. **生存偏差**：币池是「活到 2026-11 的 99 个 ASCII USDT 合约」，退市/下架的币不在库内；
   2022 年可用标的仅约 48 个，早期年份的截面很薄。
2. **日线口径**：没有盘口、冲击成本、交易所限频、借币可得性；强平用日内 low/high 近似，
   实际强平价格与滑点可能更差。
3. **资金费**：默认按净敞口计，假设多空资金费大致对冲；真实永续资金费随基差波动，
   极端行情可能显著偏离。需要保守估计时把 `funding_mode` 改为 `gross`。
4. **杠杆风险**：固定杠杆 2x 以上在本样本内已被 2025-10-10 闪崩击穿；不要用回测收益
   反推可承受杠杆。实盘应保留交易所侧的逐仓/止损与保证金缓冲。
5. **模型风险**：alpha IC 0.05~0.14、风险 AUC 0.58~0.61 都属于弱信号；LightGBM 在小
   截面、强风格切换下容易失效。默认参数在同一段样本外区间做过结构对比，存在选择偏差；
   上线前应做真正的未来样本外（2027+）或嵌套交叉验证。
6. **范围**：本仓库只做研究/回测，不含 LLM、实盘执行、账户体系、风控合规与税务处理。
